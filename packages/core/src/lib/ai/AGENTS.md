# src/lib/ai/ - LLM Utilities

Helpers for calling LLMs in a structured way. Used by extensions that need
to invoke models (critic, classifier) with consistent error handling
and result parsing.

## Files

| File                    | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `critic-registry.ts`    | Catalog of available critics (judges that evaluate LLM output). Each critic has a tier, name, and prompt template.                                                                                                                                                                                                                                                                                                                                                                                         |
| `critic-gate.ts`        | Utility-model-first gate pattern - uses a small/fast model to decide whether the full critic should run. Reduces cost.                                                                                                                                                                                                                                                                                                                                                                                     |
| `critic-stats.ts`       | Statistics on critic invocations (success rate, duration, tier distribution, Q16 token counts).                                                                                                                                                                                                                                                                                                                                                                                                            |
| `cost-report.ts`        | USD cost estimates from `critic-stats` token data (P3-25). Computes per-critic + aggregate spend at configurable pricing rates.                                                                                                                                                                                                                                                                                                                                                                            |
| `text-classifier.ts`    | Generic text classifier - runs utility model with structured schema, returns typed result.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `post-loop-classify.ts` | Thin wrapper around `classify()` bundling the 4 post-loop guarantees (signal thread, abort demotion, 8s default timeout, caller-supplied onFailure fallback). Use this for `agent_end` / post-loop LLM calls.                                                                                                                                                                                                                                                                                              |
| `language-hint.ts`      | Detects the language of input text (used to route language-specific processing).                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `llm-call.ts`           | Auxiliary LLM calls: dispatched through the session's `ctx.modelRegistry.streamSimple` (pi-core resolves credential, headers, transport), with two-tier retry, backoff, rate-limit circuit breaker, and abort handling.                                                                                                                                                                                                                                                                                    |
| `judge-budget.ts`       | The consolidated judges' output-budget contract in one place: one judge completion across the model tiers (session → utility) with no `maxTokens` on the first attempt (callLlm sizes it from the prompt), plus exactly one retry at `min(8192, model.maxTokens)` when a completion ends at its own output ceiling without a verdict. Also owns the shared outcome vocabulary (`budget-exhausted` / `unparseable` / `invalid-fields` / `call-error`). Each judge supplies its own reader for the response. |
| `payload-hygiene.ts`    | Raw-payload hygiene at the LLM-call boundary: error text collapses to one line for logs/returns (status + excerpt + type + size, base64 redacted); request-body hygiene for edge/WAF page dumps plus in-place neutralization of the edge filter's request trigger (a space inserted, text kept).                                                                                                                                                                                                           |
| `model-resolver.ts`     | Resolves the merged role (utilityModel) and the deprecated vision alias to catalog models; each accepts a scalar or an ordered list.                                                                                                                                                                                                                                                                                                                                                                       |

## Local Contracts

- All LLM calls should go through `llm-call.ts` for consistent abort/retry behavior.
- **A consolidated judge (one prompt asking for a JSON verdict) goes through `judge-budget.ts`** - never a hand-rolled `callLlm` with a small explicit `maxTokens`. Thinking tokens count against `max_tokens` on reasoning models and the channel cannot always be switched off, so a small ceiling starves the answer; `judge-budget.ts` owns the budget, the bounded retry, and the tier walk.
- All classifications should go through `text-classifier.ts` - it handles the utility-model-first gate via `critic-gate.ts`.
- **All post-loop LLM calls (agent_end, post-turn analysis, reflection, etc.) should go through `post-loop-classify.ts`** - it bundles the 4 post-loop guarantees (signal thread, abort demotion, 8s default timeout, onFailure fallback) that hand-rolled callers have repeatedly gotten wrong. See `src/extensions/heartbeat/AGENTS.md` for the abort-handling contract.
- **Direct `callLlm()` callers must thread `ctx.signal` (or the tool execute's `signal` parameter) via the conditional spread pattern** `...(ctx.signal ? { signal: ctx.signal } : {})`. Without this, ESC during the agent's main turn leaks the parallel LLM call until its own timeout fires, producing misleading "LLM error: This operation was aborted" ERROR logs. Verified by `test-direct-callers-signal-threading.mjs` for session-recall and verification-judge.
- Don't hardcode model names - use `model-resolver.ts` aliases.

## Anti-patterns

- Don't call `completeSimple` directly from extensions. Use `llm-call.ts`.
- Don't parse LLM JSON inline. Use `text-classifier.ts`, which runs the four-tier fallback and returns a parsed `ClassificationResult`.
