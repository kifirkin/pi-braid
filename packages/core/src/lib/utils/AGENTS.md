## Local Contracts

- **`injection-tracker.ts` is the canonical chokepoint for sending messages to the agent.** Don't use `pi.sendMessage` directly - use `sendTrackedMessage` so whispers get capped and tracked. The universal envelope is applied here automatically.
- **`injection-tracker.ts` also runs cross-call reprime suppression.** `sendTrackedMessage` suppresses an exact-repeat (whitespace- and digit-normalized) body re-delivered within `REPRIME_COOLDOWN_MS` in the same session - the de-bloat for the 41% of whispers that re-injected the same body turn after turn. `triggerTurn:true` wakes always pass; first occurrence and genuinely different bodies always pass. Normalization collapses digit runs to `#` (MARS dedup lesson) so ticking counters don't defeat the key (different source = different key).
- **`injection-tracker.ts` owns the delivery contract.** Every non-waking send declares `delivery: "live" | "park"`; the funnel is the one place that translates the class into pi-core's `sendCustomMessage` option shape. `live` steers a streaming run (branch 2) and appends when idle; `park` records for the end-of-turn flush (branch 4) and appends when idle. `triggerTurn: true` keeps its wake meaning; `deliverAs: "nextTurn"` passes through. pi 0.84.2 made `triggerTurn: false` park, so the live shape omits triggerTurn. See the DELIVERY CONTRACT on `sendTrackedMessage`.
- **`whisper-format.ts` is the source of truth for the envelope format.** Don't add inline prefixes like `[enforcement] ${message}` in handlers - the trunk handles the universal envelope, and any body-level sub-tags should be added inside the message body (e.g. `[dream] ...`) as a second filter level.
- See `extensions/enforcement/whisper.ts` for the pattern.
