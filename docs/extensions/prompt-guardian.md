# Extension: prompt-guardian

**Status**: 🟡 Deprecated
**Tests**: None
**Version**: v0.3.x (not maintained)

## Purpose

Previously listed/restored deleted prompts from pi's internal prompt history. Tools included `list_deleted_prompts`, `recover_prompt`, `save_current_prompt`.

## Status

This extension has been **deprecated and deregistered**. The tools are removed from `src/index.ts` but the extension source still exists for reference. Prompts are now managed entirely by `prompt-builder`.
