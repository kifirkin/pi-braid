What is pi?Что такое pi?

A minimal terminal coding harness. Aggressively extensible. Designed so you adapt pi to your workflow, not the other way around.Минимальная терминальная среда для кодинга. Агрессивно расширяемая. Создана так, чтобы вы адаптировали pi под свой workflow, а не наоборот.

Small core, big surfaceМалое ядро, большая поверхность

The session loop and four core tools (read, write, edit, bash). Customization through TypeScript Extensions, Skills, Prompt Templates, and Themes.Цикл сессии и четыре основных инструмента (read, write, edit, bash). Настройка через TypeScript расширения, навыки, шаблоны промптов и темы.

Four modes of operationЧетыре режима работы

Interactive Terminal UI (TUI), single-shot --print, machine-readable JSON, RPC (Remote Procedure Call) over stdio, plus a TypeScript SDK (Software Development Kit) for embedding in your own apps.Интерактивный TUI, одноразовый --print, машиночитаемый JSON, RPC через stdio, плюс TypeScript SDK для встраивания в ваши приложения.

JSONL tree with branching, forking, cloning, and lossy compaction. /tree lets you rewind and continue from any point in history.JSONL-дерево с ветвлением, форками, клонированием и сжатием. /tree позволяет отмотать и продолжить с любой точки истории.

Pi PackagesПакеты Pi

07 — Customization07 — Настройка
Sessions

Branching sessions, lossy compactionВетвление сессий, сжатие с потерями

Every turn is a node in a JSON Lines (JSONL) tree. /tree rewinds and forks in place. Long sessions stay fast because older turns are summarized — but the originals are never lost.Каждый шаг — это узел в JSONL-дереве. /tree отматывает и форкает на месте. Длинные сессии остаются быстрыми, потому что старые шаги суммируются — но оригиналы никогда не теряются.

# Session tree (one file, in-place branching)
● user:    "summarize pi"
 ├ ●  asst:   [read README.md, write response]
 ├ ●  user:   /fork  ← branch point
 │  ├ ●  asst:   "pi is a minimal harness..."   (branch A)
 │  └ ●  asst:   "let me show you the API..."   (branch B)
 └ ●  user:   "compare it to X"
    └ ●  asst:   [diff against README, ...]

# Compaction — lossless on disk, lossy in context
$ pi /compact "keep the decisions, drop the chatter"
