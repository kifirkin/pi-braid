# Tool Description Rewrite Plan

## Goal
Rewrite the first sentence of each braid tool's `description` field to include both "what it does" and "when to use" — matching skills' advice-style tone. The `firstSentence()` function in the prompt builder extracts this first sentence for the tool listing.

## Principles
- Keep the original description style (technically precise, tool-oriented)
- Add "Use when..." or "Call this when..." or "Use for..." to the first sentence
- Concise: first sentence should be ≤120 chars
- After the first sentence, keep existing parameter documentation as-is
